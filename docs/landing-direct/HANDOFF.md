# Handoff: редизайн `/landing-direct/`

## Цель

Переделать только страницу оффера «Лендинг + настройка Яндекс.Директа — 35 000 ₽, 4 дня». Исследовательская основа: [01-research.md](01-research.md). Структура и финальная copy готовы в [03-design-spec.md](03-design-spec.md); последовательное исполнение описано в [02-redesign-plan.md](02-redesign-plan.md). Открытые условия исключены из обещаний и не останавливают реализацию.

## Обязательные ограничения

- Не менять цены всей линейки: `pricing.02` действует для этой campaign-страницы.
- Не переносить claims, цены, сроки и гарантии конкурентов на Сергея.
- Поиск и РСЯ подтверждены; рекламный бюджет платится отдельно в кабинете клиента.
- Не обещать ведение, аналитику/цели, количество правок, производство контента и сопровождение без отдельного источника.
- Четыре дня стартуют после согласования задачи и получения необходимых материалов/доступов; календарная трактовка и полный список входов открыты.
- Менять только `/landing-direct/`; главную, `/landing-wow/`, `V3Motion.astro` и общую V3-систему оставить вне scope. Для direct использовать отдельный компонент и локальные стили/motion.
- Сохранить BaseLayout и `noindex`; исследование не означает готовность к публикации.

## Файлы реализации

- Route: `webApp/src/pages/landing-direct.astro`
- Шаблон: `webApp/src/components/v3/DirectLanding.astro`
- Локальные direct CSS/motion: `webApp/src/styles/direct-landing.css`, `webApp/src/components/v3/DirectLandingMotion.astro`; `CampaignLanding.astro`, `campaignLandings.ts` и `campaign-landing.css` оставлены для WOW и общего кода
- Главная вне scope: `webApp/src/pages/index.astro`
- Глобальный motion вне scope: `webApp/src/components/v3/V3Motion.astro`
- Общие токены вне scope: `webApp/src/styles/v3.css`
